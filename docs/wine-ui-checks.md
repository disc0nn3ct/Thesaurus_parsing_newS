# Винотека: меню, архив и проверка расчётов

Экран «Моя винотека» показывает сводку запасов, оценку, открытый и зафиксированный
условный результат. Бутылки открываются через «Винный погреб · запасы и архив».
В погребе есть «В запасе», «Архив · выпито» и «Все покупки». Архив содержит события
списания с датой, количеством и замороженной оценкой, включая частично выпитые партии.
После полного списания партия исчезает из запасов, оставаясь в архиве и покупках.

На главной есть «Дозаполнить сведения». В форме сначала показан поиск, затем
незаполненные поля, затем известные. Изменения проверяются перед сохранением;
финансовые данные и количество не меняются от разметки характеристик.

Проверки выполняются через реальные обработчики меню с тестовыми объектами Telegram
и локальной SQLite. Магазинные запросы в этих сценариях не выполняются. PNG графика
дополнительно просматривается визуально. Это проверка маршрутов, кнопок и расчётов,
а не автоматическое управление мобильным приложением Telegram.

## Контрольный расчёт

Три бутылки куплены по 1000 ₽. До независимой оценки открытый результат неизвестен.

| Событие | Остаток | Открытый результат | Зафиксированный | Общий |
|---|---:|---:|---:|---:|
| Оценка 1200 ₽ | 3 | +600 ₽ | 0 ₽ | +600 ₽ |
| Выпита одна по оценке 1200 ₽ | 2 | +400 ₽ | +200 ₽ | +600 ₽ |
| Оставшиеся оценены по 900 ₽ | 2 | −200 ₽ | +200 ₽ | 0 ₽ |
| Выпиты оставшиеся две по оценке 900 ₽ | 0 | 0 ₽ | 0 ₽ | 0 ₽ |
| Новая магазинная цена 3000 ₽ после списания | 0 | 0 ₽ | 0 ₽ | 0 ₽ |

Первая запись архива остаётся +200 ₽; вторая — −200 ₽. Более поздняя цена не меняет
эти записи и прошлые точки графика. Нет цены покупки или оценки — результат
неизвестен, а не равен нулю. Нулевая явно заданная оценка остаётся допустимым убытком.

## Проверяемые сценарии

- На главной нет строк бутылок; в погребе список разбит по страницам.
- Переходы «Назад» из карточки сохраняют страницу списка.
- Выбор списания не меняет остаток до подтверждения; повторное подтверждение
  не списывает бутылку второй раз.
- Частично выпитая партия одновременно присутствует в запасах и в истории списаний.
- В архиве сохраняются дата, количество, цена покупки, оценка при списании и результат.
- Статистика стран/регионов/сортов/годов учитывает покупки, остатки и списания.
- Дозаполнение меняет существующую партию и статистику без новых покупок и расходов.
- Перезапуск сохраняет данные, черновики уточнений и зафиксированные результаты.
- Пользователь не читает чужую винотеку; администратор просматривает чужие данные
  без права менять запасы или характеристики.
- Экспорт сохраняет покупки, историю оценки и зафиксированные списания.

График содержит стоимость запаса, условный результат и размер запаса отдельно.
Показано последнее сохранённое состояние за день по Москве. Неизвестные значения
оставляют разрыв; отдельные линии показывают открытый, зафиксированный и общий
результат. Списание учитывается в истории сохранённых состояний с момента записи;
дата фактического употребления отдельно доступна в архиве.

Основные сценарии: `tests/test_wine_cellar_ux.py`, `tests/test_telegram_wines.py`,
`tests/test_wine_details.py`, `tests/test_wine_cellar.py`, `tests/test_wine_jobs.py`.
