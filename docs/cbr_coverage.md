# Проверка загрузчиков Банка России

Проверено 7 октября 2026 года по официальным HTML, XML, SOAP и архивным выгрузкам ЦБ. Запросы выполнялись последовательно, не чаще одного запроса в секунду. Telegram, платные API и рабочая база пользователей не использовались.

Проверено 145 числовых адаптеров/вариантов: 144 получили числовые данные, 1 — только пропуски либо пустой диапазон. Ошибок разбора: 0. Числовые данные есть у всех 29 корневых разделов через их вложенные наборы.

Ежедневные/недельные пробы охватывают последние два доступных года; остальные — до двадцати лет. Архивная выборка отсчитывается от последнего опубликованного архивного периода. Проверка доступности не означает пригодность каждого ряда для прогноза: проверяются частота, свежесть, полнота, единицы и количество наблюдений.

## Воспроизведение

```powershell
.\.venv\Scripts\python.exe scripts/check_cbr_coverage.py --live
```

По умолчанию используются системные настройки сети. `--direct` явно отключает использование прокси переменных окружения только для этого диагностического запуска. Результат записывается в `.test-tmp/cbr-coverage/verified.json`; в нём указаны URL, периоды, тип данных, единицы и числа наблюдений каждого адаптера. Ошибки сети записываются без адресов прокси и значений секретов.

В обычной работе: **Аналитика → Показатели Банка России → группа → база → Подключить и загрузить → Наборы и показатели**. Подключение выполняет администратор. После загрузки подписчик выбирает ряд и строит график, сравнение или экспорт по своей истории. Расписания включаются отдельно.

70 сокращённых примеров официальных таблиц сохранены в `tests/fixtures/cbr_sources.json`. Автономные тесты проверяют разбор, запись в SQLite, доступность для аналитики, единицы, пропуски, права, параметры и повторную загрузку. Сокращённые примеры не заменяют live-проверку доступности сайта.
