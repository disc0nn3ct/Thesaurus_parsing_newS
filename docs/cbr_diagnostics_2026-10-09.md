# Диагностика подключённых наборов ЦБ · 09.10.2026

Проверены ответы 29 подключённых числовых адаптеров ЦБ: 24 вернули значения, 5 — корректный пустой выбранный интервал. Ошибок разбора в этой проверке не было. Это проверка выбранных интервалов, а не всей истории или всех отключённых наборов каталога. Код: `scripts/audit_cbr_sources.py`; тесты: `tests/test_cbr_source_reliability.py`.

Дополнительно воспроизведены семь ранее падавших исторических интервалов на сохранённых официальных ответах. Пять не содержат наблюдений; месячный MIACR содержит одну заполненную таблицу и три пустые. Шесть наборов успешно обновлены. В седьмом — архиве MIACR 1996–2000 — источник содержит разные значения на одинаковую дату. Однозначная часть сохранена; 757 противоречивых наблюдений изолированы и записаны в журнал целостности. Этот набор честно остаётся частичным: выбирать одно из противоречащих значений без проверки методики нельзя.

## Причины

- Официальное сообщение об отсутствии информации обрабатывалось только для инфляции. У [RUONIA](https://cbr.ru/hd_base/ruonia/dynamics/), вмененной ставки CNY, старых металлов и архива MIBID оно ошибочно считалось исчезновением таблицы.
- [Кривая доходности](https://cbr.ru/hd_base/zcyc_params/) за 28.02–18.03.2022 возвращает таблицу с исходными заголовками без строк. Парсер ошибочно считал её изменённой.
- [Месячный MIACR](https://cbr.ru/hd_base/mkr/mkr_monthes/) за октябрь 2008 года содержит данные лишь в первой из четырёх таблиц. Пустые остальные таблицы прерывали весь разбор.
- [Архив MIACR](https://cbr.ru/hd_base/mkr/retro/mkr_base_old/) возвращает противоречивые дубликаты без различающей маркировки. Например, MIBID на 30.11.1999 для одного дня указан как 7,63 и 16,40. При загрузке одинаковые дубликаты объединяются, спорные даты сохраняются как NULL с качеством `source_conflicting_values`. Все варианты остаются в инциденте `source_conflict`; они не усредняются и не выбираются по порядку строк. Предупреждение остаётся видимым и после повторного обновления из кэша. Это выявленная неоднозначность публикации; утверждать, что одна из строк является месячной средней, оснований пока нет.
- Исторические пропуски после часового кэша снова попадали в очередь загрузки. Теперь подтверждённое отсутствие старше 30 дней запоминается; обычное обновление оставляет сохранённые значения неизменными. Недавние периоды повторно проверяются, полная сверка доступна отдельно.

## Проверки качества расчётов

Пропуски остаются пропусками. Волатильность рассчитывается только по соседним расчётным датам без соединения значений через отсутствующее наблюдение; при нехватке доходностей возвращается отсутствие оценки. Факты вне календаря не увеличивают покрытие и явно отмечаются. В отчёте указан диапазон покрытия и дата предыдущего наблюдения; изменение процентной ставки подписано в п.п. Корреляции выводятся с названиями рядов, числом пар, лагом и поправкой на множественные проверки.

Результаты не устанавливают причину движения курса и не являются проверкой прогнозной модели. Редкие события, архивные интервалы и задержка публикации сами по себе не доказывают неисправность источника.

## Локальное восстановление

Перед дозагрузкой сделана резервная копия SQLite. После исправлений добавлено 27 824 записи, включая явные пропуски на спорные даты. Сравнение с копией показало: прежние непустые значения и их `retrieved_at` не изменены. `PRAGMA quick_check`: `ok`. Последний архив обработан повторно из сохранённого ответа без нового запроса к ЦБ. Настройки пользователей и история других проектов сохранены.

Повторная проверка 29 подключённых адаптеров, теперь с контролем противоречивых дубликатов, завершилась с 24 заполненными и 5 корректно пустыми интервалами, без ошибок. Старая неоднозначность MIACR находится вне этих выбранных интервалов и отдельно сохранена в журнале. Полный автономный набор: 646 тестов успешно; Ruff и `git diff --check` прошли. Проверки не отправляли тестовых рассылок и не использовали платные API. После восстановления запущен один экземпляр сервиса, Google Trends остаётся выключенным.
