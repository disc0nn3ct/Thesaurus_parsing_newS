# Характеристики вина для учёта и статистики

Страна, винодельческий регион и сорта винограда сохраняются в отдельных полях
таблицы `wine_attributes`, связанной с партией в `wine_lots`. Вместе с ними
сохраняются ссылки и время получения сведений по каждому полю. Год конкретной
бутылки остаётся в `wine_lots.vintage`.

## Чеки и автоматическое заполнение

В карточке товара есть «Автозаполнение». Перед первым включением бот показывает
сайты подключённых источников и объясняет, что отправляется название вина и
производитель. Суммы, персональные данные и фискальные реквизиты не отправляются.
Личный выбор сохраняется для следующих чеков; изначально автоматический поиск
выключен. Источники подключает администратор.

После включения сведения ищутся в фоновых заданиях при распознавании и просмотре
чека. Повторное открытие не создаёт новый поиск для неизменившегося товара.
«Найти сведения о вине» запускает явное повторное обновление. Во время поиска
карточка предлагает «Обновить карточку». Результаты не создают запасы или расходы:
покупка сохраняется отдельным подтверждением пользователя.

При однозначном совпадении заполняются отсутствующие поля. При нескольких
согласованных карточках можно объединить устойчивые характеристики из разных
источников. Конфликтующие значения не подставляются. Год текущего товара магазина
не означает год купленной бутылки: найденные винтажи показаны для проверки,
а подтверждение года с этикетки выполняется отдельно.

При изменении года карточка предлагает кнопки с найденными винтажами, например
2015/2016/2017/2019/2024. Такие же варианты доступны для производителя, объёма,
страны, региона и сортов. Повторы объединяются, разные значения помечаются как
требующие уточнения. Порядок кнопок не означает вероятность совпадения.
Можно выбрать значение с этикетки или ввести своё вручную. Выбор меняет только
одно поле в черновике, показывает «было → стало» и не сохраняет запасы автоматически.
Перед применением повторно проверяются права, источник, срок и версия поиска;
кнопка из предыдущего поиска не может применить другой вариант с тем же номером.

Ручные исправления не заменяются автоматическими. Изменение названия, производителя,
года или объёма удаляет сведения, автоматически скопированные для прежней идентичности,
и делает прежний результат поиска недействительным. В каждом сетевом шаге повторно
проверяются права пользователя, актуальность черновика и подключённые источники.

## Дозаполнение сохранённых вин

В статистике и винотеке есть «Дозаполнить недостающие сведения»: список партий,
у которых не заполнены производитель, год/NV, страна, регион или сорта.
У каждой собственной партии доступно «Уточнить характеристики», в том числе
для полностью выпитых вин. Можно уточнить название, производителя, год, объём,
страну, регион и сорта. Текущее значение показывается перед вводом.
Поиск использует подключённые источники и личную загрузку Vivino, предлагает
варианты по каждому полю; они не применяются автоматически. Год проверяется
по этикетке. Неизвестные значения допустимо оставить пустыми.

Правки сохраняются как личный черновик на сутки. Кнопка «Сохранить уточнения»
применяет показанные изменения «было → стало» к существующей партии и статистике.
Количество, цена и дата покупки, расходы, история оценок, снимки портфеля и
зафиксированные списания не меняются. Изменение чужой винотеки запрещено даже
из административного просмотра. Если характеристики партии изменились после
открытия черновика, сохранение отклоняется до повторного открытия.

## Источники и фактический охват

- Декантер: общий поиск по очищенному названию и проверка основной карточки вина.
- Личная загрузка Vivino: локальное сопоставление записей без отправки каталога на сайт.
- Бахетле и VinumDay: дополнительные справочники характеристик. Сейчас проверенные
  маршруты их карточек добавлены для Bariloche Malbec; это не общий поиск по их ассортименту.

Открытые страницы Bariloche Malbec проверены сетевым кодом бота 12 октября 2026:
Бахетле публикует производителя «ФАМИЛИЯ ШРЕДЕР», Аргентину и Мальбек;
VinumDay — Familia Schroeder, Аргентину, Патагонию, Мальбек и винтаж карточки 2024.
Все характеристики читаются из страниц при запросе; таблица маршрутов содержит
только адреса, без заранее записанной страны, региона или производителя.

После отдельного согласия владельца 12 октября 2026 проверен сохранённый чек:
шесть различных названий, запросы только к `decanter.ru`, `bahetle-sib.ru`
и `vinumday.com.br`. Bariloche Malbec, San Valentin Garnacha и Frontera Chardonnay
дают согласованные характеристики для автоматического заполнения. Для Casillero
del Diablo Merlot и Gran Castillo Malbec остаётся выбор варианта; для сокращения
«Дж.Лав Ахашени W» проверяемого совпадения нет. Эти результаты не означают,
что любой товар с похожим названием можно автоматически считать найденным.

В ходе проверки исправлено объединение синонимов «Гренаш/гарнача» и «Гарнача».
Пустой список сортов считается отсутствующим значением и может быть дополнен;
непустые ручные значения сохраняются. Для явного повторного фонового поиска
после исправления доступен `queue_lookup(..., automatic=True, refresh=True)`:
выполняющееся задание всё равно используется повторно, без создания дублей.

Согласие владельца сохранено в `wine_metadata_consent:<user_id>` с перечнем
трёх сайтов и отправляемых полей. Автозаполнение включено только для его учётной
записи; предпочтения остальных пользователей не менялись.

Цены справочников, наличие за рубежом и иностранная валюта не используются
для оценки московского винного портфеля. Недоступный источник не отменяет результаты
другого источника. Если подтверждения нет, поле остаётся неизвестным.

## Статистика и сохранность

В `/cellar` пункт «Статистика · страны, регионы, сорта и годы» группирует все
покупки, текущий запас и выпитые бутылки. Неизвестные значения включаются в отдельную
группу. Купаж считается в каждом указанном сорте, поэтому суммы по сортам могут
быть больше числа бутылок. Все поля доступны в CSV, Excel и HTML.

Версия схемы винотеки 3 добавляет таблицу характеристик. Перед миграцией создаётся
резервная копия SQLite. Покупки, списания, цены, финансовый журнал, чеки и права
не заменяются. Сведения из прежних структурированных примечаний «Страна: …;
Регион: …; Сорта: …» переносятся с отметкой `legacy_notes`.
